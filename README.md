# WebFormularElemente

Ein Webprojekt zur Einführung in die Verwendung und Verarbeitung verschiedener Formularelemente innerhalb einer Webseite.

## Beschreibung

Das Projekt **WebFormularElemente** beschäftigt sich mit den Grundlagen der Erstellung und Verwendung von HTML-Formularelementen. Im Mittelpunkt stehen die Erfassung von Benutzereingaben, die Gestaltung interaktiver Formulare und die Verwendung verschiedener Eingabemöglichkeiten.

## Funktionen

- Erstellung und Darstellung von Webformularen
- Verwendung unterschiedlicher Formularelemente
- Eingabe von Texten und anderen Benutzerdaten
- Auswahlmöglichkeiten durch Checkboxen und Radiobuttons
- Verwendung von Dropdown-Listen und Schaltflächen
- Grundlagen der Formularverarbeitung

## Technologien

- HTML
- Webtechnologien
- Microsoft Visual Studio

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/WebFormularElemente.git
   ```

2. Das Projekt in Visual Studio öffnen.
3. Falls erforderlich, die Projektabhängigkeiten installieren.
4. Die Anwendung starten.
5. Die Webseite im Browser öffnen.

## Ziel

Das Projekt dient dem Verständnis der verschiedenen HTML-Formularelemente und ihrer Verwendung innerhalb einer Webanwendung. Dabei werden grundlegende Konzepte der Dateneingabe, Benutzerinteraktion und Formularverarbeitung kennengelernt.
